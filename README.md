# ⚡ Zoom Bot

Инструмент для массового подключения ботов к веб-конференциям Zoom с управлением микрофоном и воспроизведением аудио.

![version](https://img.shields.io/badge/version-1.0.0-green)
![python](https://img.shields.io/badge/python-3.10%2B-blue)
![platform](https://img.shields.io/badge/platform-Windows-lightgrey)

**Автор:** VDteg111 / x3malgameYT

---

## Возможности

- Массовый запуск ботов с именами из файла
- Каждый бот — отдельный профиль Chrome, без вашего аккаунта
- Подмена микрофона на WAV-файл (все боты играют музыку)
- Управление всеми ботами сразу: MIC ON / MIC OFF / Music Start / Music Stop
- Управление каждым ботом отдельно
- Экономный режим для слабых ПК
- Headless-режим (без окон)
- Кнопка обновления прямо из приложения
- Тёмный интерфейс

---

## Требования

- Windows 10 / 11
- Google Chrome (обязательно установлен)
- Python 3.10+ (только для запуска из исходника)

## Быстрый старт

### Вариант 1. Готовый `.exe`

1. Скачайте `ZoomBot.exe` из раздела **Releases**
2. Положите рядом с ним:
   - `names.txt` — список имён
   - `audio.wav` — аудиофайл
3. Запустите `ZoomBot.exe`
4. Загрузите имена и аудио через кнопки в приложении
5. Вставьте ссылку на урок
6. Укажите количество ботов
7. Нажмите **Запустить**

### Вариант 2. Из исходника

```bash
pip install selenium
python zoom_bot_app.py
```

## Формат аудио

Аудиофайл должен быть в формате:

- **WAV**
- **48000 Hz**
- **16 bit**
- **Стерео (2 канала)**

Если файл в другом формате — используйте ffmpeg:

```bash
ffmpeg -i input.mp3 -ar 48000 -ac 2 -c:a pcm_s16le output.wav
```

Приложение показывает параметры WAV при загрузке. Если формат не 48000/16/стерео — звук может не пойти.

---

## Формат `names.txt`

По одному имени на строку, кодировка UTF-8:

```
Иван Петров
Мария Сидорова
Алексей Козлов
```

---

## Формат ссылки

Для веб-клиента Zoom используйте ссылку в формате:

```
https://us05web.zoom.us/wc/join/XXXXXXXXXXX?pwd=...
```

Если у вас обычная ссылка вида `/j/`, замените `/j/` на `/wc/join/`.

## Управление

| Кнопка | Действие |
|--------|----------|
| Загрузить имена | Выбрать `names.txt` |
| Загрузить аудио | Выбрать WAV или MP3 |
| Запустить | Запустить всех ботов |
| Остановить | Остановить всех ботов |
| MIC ON всем | Включить микрофон у всех |
| MIC OFF всем | Выключить микрофон у всех |
| Музыка заново всем | Перезапустить аудио у всех |
| Стоп музыку всем | Остановить аудио у всех |

В панели «Отдельное управление» — те же действия для каждого бота по отдельности.

## Обновление

Нажмите кнопку **⟳ Обновить** в верхней панели приложения. Скачается свежая версия кода с GitHub.

Для `.exe` версии скачается `new_version.py` рядом с приложением. Чтобы применить — пересоберите `.exe` через `build_exe.bat`.

---

## Важно

- Каждый бот заходит как **гость**, без вашего аккаунта Zoom
- Все боты выходят с **одного IP** — если нужны разные, используйте прокси
- Zoom может заглушить ботов через **Mute All** — это ограничение платформы
- Организатор может удалить ботов из урока вручную
